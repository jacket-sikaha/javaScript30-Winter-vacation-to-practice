为什么没有 props / Context 也会 render？

这就是这道题最重要的知识点。

你可以记住：

父组件重新 render，默认会导致它下面的普通子组件也参与 render/reconciliation，即使子组件的 props 没变化。

---

React.memo 主要解决的是父组件 render 导致的 props 没变化子组件跟着 render；
但如果子组件自己通过 useContext 订阅了 Context，Context value 发生变化，React.memo 也挡不住。

---

一个组件 render 的原因可能很多：

组件 render
├── 自己的 state 更新
├── 父组件 render
├── props 变化
├── Context value 变化
└── 其他 React 更新机制

---

React.memo
│
├── 父组件 render
│ ↓
│ props 没变 → 可以跳过
│
├── 父组件 render
│ ↓
│ props 变了 → render
│
├── 自己 state 变了 → render
│
└── useContext 的 value 变了 → render

    Context	Zustand

核心目的 跨层级传递数据 共享状态管理
