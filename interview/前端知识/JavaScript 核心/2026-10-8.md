2. 为什么需要 getOwnPropertyDescriptor？
   因为 Object.keys() 不仅需要知道有哪些属性，还需要知道哪些属性是可枚举的。

可以这样理解：

- ownKeys：这个对象有哪些自有属性键？
- getOwnPropertyDescriptor：这个属性的 enumerable 是 true 还是 false？

注意：Object.keys() 只返回可枚举的字符串键；Symbol 键也不会出现在结果中。即便对proxy用也遵循这个规则。

2. 关键知识点

- construct：拦截通过 new 创建实例的操作。
- ProxyPerson("Alice")：普通函数调用，不触发 construct，而是触发 apply（如果定义了该陷阱）。
- Reflect.construct(target, args, newTarget)：执行构造过程，并保留 newTarget 对原型选择等行为的影响。
  还有一个限制：只有目标本身是可构造的对象，才能使用 construct 陷阱；例如普通函数通常可以构造，但箭头函数不可以。

---

JavaScript 有一条规则：

- 构造函数显式返回一个对象，实例结果会采用该对象。
- 构造函数显式返回一个原始值（例如字符串、数字、布尔值），这个返回值会被忽略，最终得到新创建的实例对象。

2. Proxy.revocable记住这三个结论

调用 revoke() 后：

- proxy 变量仍然引用着这个代理对象。
- 只是代理与其目标对象之间的代理操作被禁用了。
- 之后通过 proxy 进行属性访问、赋值、in 检查、删除等操作，都会抛出 TypeError。
- target 本身不受影响。
- revoke() 之后：通过代理进行属性读取、赋值等操作会抛出 TypeError，而不是简单返回 undefined。
