联合索引运行原理

```js

INDEX(a, b, c)

        等值          范围           缺失
         ↓             ↓              ↓

A:     a = 1        b = 2         c = 3
       ─────        ─────         ─────
          ✓             ✓              ✓
       可以定位      可以定位       可以定位


B:     a = 1        b > 2         c = 3
       ─────        ─────         ─────
          ✓             ✓              ×
       可以定位      范围定位       不能继续定位
                                    ↑
                                  可能 ICP


C:     a = 1        b 缺失         c = 3
       ─────                       ─────
          ✓                           ×
       可以定位                   不能跳跃定位
                                    ↑
                                  可能 ICP


D:     a 缺失       b = 2         c = 3
                     ↓             ↓
                   基本无法从 a 开始定位

```

ref：
可能找到很多条

const：（where 用 ID 主键查询）
最多找到一条

主键/唯一索引 + 等值
↓
const

普通索引 + 等值
↓
ref

索引 + 范围
↓
range

没有合适索引
↓
ALL
